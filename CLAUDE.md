# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

This is a **bootstrap repo**: a source of shared, reusable project scaffolding (e.g. `.gitignore`, `.editorconfig`, and similar repo-level config) used when creating new repositories or updating existing ones to a common baseline.

## Working in this repo

- Files here are templates meant to be copied into *other* repositories. Keep them generic and reusable rather than tailored to this repo.
- When changing a template, consider its effect on existing repos that already adopted it — prefer additive, backwards-compatible changes.
- There is no build, lint, or test tooling yet. Update this file once a layout, sync/apply script, or validation tooling is added.
